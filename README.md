# SshMagic

A mobile SSH client for iPhone and Android with saved connections and tmux integration.

## Features

* **Saved connections**: name, host, port, user, and password or private key (PEM, with optional passphrase). Secrets live in the iOS Keychain / Android Keystore, never in plain preferences.
* **Host key verification**: trust-on-first-use with a clear warning if a server's key changes.
* **Full terminal**: xterm-compatible emulator (colours, vim, htop, etc.), resizes with the screen, adjustable font size.
* **Phone-friendly keys**: Esc, Tab, sticky Ctrl, arrows, Home/End/PgUp/PgDn and common shell symbols.
* **tmux integration**
  * List the sessions running on a server (windows, attached state, age).
  * Attach to a session, or create one (`tmux new-session -A`), rename it, or end it.
  * Per-connection default session and "Open tmux on connect", so tapping a server drops you straight back into your session.
  * A tmux toolbar for prefix shortcuts: new window, next/prev, window list, splits, pane switch, zoom, scroll mode, detach.

## Why Flutter

* One Dart codebase compiles to native iOS and Android binaries.
* The two hard parts of an SSH client have mature pure-Dart packages from the same maintainers: [`dartssh2`](https://pub.dev/packages/dartssh2) (SSH protocol, PTY, exec) and [`xterm`](https://pub.dev/packages/xterm) (terminal emulator widget). They are what the open-source TerminalStudio app is built on.
* React Native has no maintained JavaScript SSH implementation; it would need native modules on both platforms plus a WebView-based terminal.

## Project layout

```
lib/
  models/connection.dart          connection profile + secrets
  services/connection_store.dart  persistence (prefs + secure storage), known hosts
  services/ssh_service.dart       connect/auth, host key prompt
  services/tmux_service.dart      list/attach/rename/end tmux sessions
  screens/                        connections list, editor, tmux sessions, terminal
  widgets/                        extra-keys and tmux toolbars
android/, ios/                    only customised files are committed; the rest is
                                  generated by scripts/bootstrap_platforms.sh
fastlane/Fastfile                 iOS signing + TestFlight upload
.github/workflows/ci-cd.yml       analyze, test, Android APK/AAB, iOS IPA/TestFlight
```

## Develop locally

```bash
./scripts/bootstrap_platforms.sh   # once: generates missing android/ios files
flutter pub get
flutter run                        # pick a simulator/emulator or a connected device
flutter test
```

Requires Flutter 3.47 (the version pinned in CI). iOS builds need a Mac with Xcode.
